**About**

This is a maths quiz created with Python using the Tkinter interface. It lets users log in, select a difficulty level, answer maths questions, and see their scores.

**How to Use the Maths Quiz**

1. Start the application.
2. Create an account by filling in your username and password and clicking Sign Up.
3. Login using your username and password.
4. Select a difficulty: Easy, Medium, and Hard.
5. Enter the answers to each of the maths questions and click on Submit.
6. You have 3 lives in the beginning.
7. Correct answers award you 1 point each.
8. Incorrect answers deduct 1 life from your total number of lives.
9. When you run out of lives or when you answer all the questions, the quiz ends.
10. The scores are saved automatically.
11. Press Scoreboard under the menu option to check past scores.
12. Press Back to go back to the previous menu and Quit to exit the program.
